# 产品数据与能力界面边界

本文件承接 [前端总览](../AGENTS.md) 的产品页面细则。产品 UI 可以组合 Gateway 数据，却不能成为资源授权、文件正文或运行时 Skill 身份的权威来源。

## 文件中心

- 产品文件中心读取 `GET /api/product/v1/files` 的 owner-scoped 快照。扩展在首次访问、超过五分钟或用户明确刷新时，才从 Gateway 最多 10,000 条的有界元数据 reader 重建；每位 owner 有 30 秒刷新冷却和数据库租约，避免重复或跨实例同时扫描。
- 搜索与每页 50 条的分页使用已保存的元数据，切页不能重新扫描用户目录。仅匹配文件名、会话名和项目名，不读取文件正文、宿主路径或授权凭据。API 的 offset 契约还供其他消费者使用，修改时应保持兼容。
- 刷新失败保留旧快照并标记陈旧；延迟刷新公开 `catalog_refresh_deferred`。有界目录不完整时必须继续显示覆盖提醒。每个产物 URL 仍走 Gateway owner 检查；输出产物当前只读，因为 Gateway 没有输出删除契约。
- 文件删除提交期间确认弹窗保持打开并锁定关闭路径；失败时在弹窗内显示双语产品提示并允许重试，保留当前列表行，原始 API detail 只进入诊断日志。只有 Gateway 删除成功后才能关闭弹窗、移除列表行并使该 owner 的目录缓存失效。新增来源要复核 owner 过滤、有界扫描、部分结果提示和稳定分页。

## 项目配置读取

- `GET /api/projects/config` 返回项目指令字节上限与回收站保留天数，Gateway 要求 `projects:read`。所有 `useProjectsConfig` 调用点显式传入权限状态；明确撤权时隐藏旧值、取消请求并移除配置缓存。项目详情页由仍挂载的页面级 hook 管理这次读取，避免切换权限后子标签卸载导致在途请求失去取消边界。老版本 Gateway 不提供此接口时继续使用本地默认值，保存长度仍由 Gateway 的 422 校验兜底。

## 产品管理审计

- 服务端动作码是稳定 API。新增产品审计事件时同步更新 `product-admin-page.tsx` 的动作、资源和结果映射、两份 locale 与类型，并补桌面和移动 DOM 回归；未知动作须有可读回退。展示层只翻译稳定代码，不得把设置值、异常正文、文件内容或凭据加入事件。
- 审计 API 的 `has_more` 通过多取一条结果精确判断是否有下一页。前端 DTO 保持该字段可选，仅在旧 Gateway 不返回时按本页长度回退。
- 记忆管理使用稳定的 `memory.*` / `memory.fact.*`；事实 ID 可定位记录，记忆正文不能进入事件。自建 Agent 和用户资料使用 `custom_agent.*`、`user_profile.update`；Agent slug 只定位对象，SOUL、描述、模型配置和 `USER.md` 正文不得送入或展示为审计字段。
- 会话管理包括 `thread.create`、`thread.branch`、`thread.update`、`thread.move`；上传/删除使用 `upload.create`、`upload.delete`。会话标题、项目 ID、消息 ID 和文件名都不是审计字段。
- Skill 安装、编辑、删除、回滚、启停及缓存刷新使用 `skill.*`，只记录动作类型，不记录 Skill 名称、正文、归档文件名或内容。只有持久化成功后才记录成功事件；失败或安全检查拒绝不得记成成功。

## 能力中心

- `/workspace/capabilities` 组合 Plugins 与 Skills 导航。Plugins 复用现有 MCP manager 和延迟加载的飞书配置弹窗；安装、OAuth、写入权限及缓存归属仍由现有 hooks 管理。
- Skill 卡片名称和摘要只属于展示元数据，运行时名称及完整描述保持不变。公共 Skill 的展示 key 必须读取 `skills/public/*/SKILL.md` frontmatter 的 `name`，不能假定目录名就是运行时 ID；自定义、集成和 legacy 来源保持区分，启用开关以展示名命名。Community 目前支持归档导入，不是远程市场；截图 E2E fixture 是演示数据。
- 飞书安装、连接、切换应用及授权失败经 `src/core/integrations/lark/error-feedback.ts` 映射为双语操作提示；原始异常只留诊断日志。状态读取失败也不直接显示异常正文，同时保留管理员权限专用提示，以及自动授权等待超时后的“仍在等待”恢复语义。
- Settings > Subagents 与自定义智能体设置共用运行时子智能体目录。目录读取按 `subagents:read` 控制；明确撤权时取消在途请求并清除 React Query 缓存。自定义智能体设置无权读目录时禁用绑定编辑，并在保存其他字段时省略 `allowed_subagents`，避免把不可见目录误保存为空白名单；有权限时保留未出现在目录中的旧绑定，供用户明确移除。Gateway 每次读取和写入仍负责最终授权。
