# Flow Desk Documentation

Flow Desk is a self-hosted workspace for research, conversations, files, and scheduled work. Its application pages and product data are maintained in this repository; the agent runtime is built on the open-source DeerFlow Harness.

These guides cover both operating the product and understanding the engine boundary. Keeping the two clear makes configuration and future DeerFlow upgrades easier to review.
