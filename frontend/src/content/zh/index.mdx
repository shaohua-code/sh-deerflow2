# Flow Desk 文档

Flow Desk 是一个可自托管的智能工作空间，用于研究、对话、文件和计划任务。产品页面与产品数据由本仓库管理；Agent 运行时基于开源 DeerFlow Harness。

文档同时介绍产品运维和引擎边界。区分这两层可以帮助你正确配置，并更容易评估 DeerFlow 后续升级。
